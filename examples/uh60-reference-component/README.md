# UH-60 published-reference component evidence

Run:

    python3 examples/uh60-reference-component/compare.py \
      > build/uh60-reference-component.json

This is an executable analytical verification of the UH-60 main-rotor
geometry transcription from NASA TM-85890 Table 1. It derives disk area,
disk loading, tip speed and solidity from the cited inputs. It is not a
published-simulation comparison, flight-data validation, or validation of
Souxmar F1.
